# pawabase-website

The Pawabase marketing site: Vite + React 19 + TanStack Router, styled with the
same design tokens, type scale and Iconsax Bulk icon set as Pawabase Studio.

```bash
bun install
bun run dev      # http://localhost:5173
bun run build
bun run typecheck
```

Routes live in `src/routes` (file-based, the tree is generated by
`@tanstack/router-plugin`). The single landing page is
`src/pages/Landing.tsx`, with its sections in `src/components/landing`.

Design tokens are defined once in `src/styles.css` under `@theme`; panel,
button and label primitives sit below them as plain classes.

## SEO and sharing

`bun run build` also writes each page's own HTML (title, description, canonical address, share tags, structured data and the rendered
content), plus `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt` and `404.html`, and fails if a title or description is too long or
repeated, a page lacks a single `<h1>`, or an image has no alt text.

- Every page is listed once in `src/seo/pages.ts`: change a title, description or priority there, and add new pages there.
- The site address comes from `VITE_SITE_URL` (default `https://pawabase.com`); set it to build for another domain.
- `bun run seo:images` remakes the share image (`public/og.png`) and the app icons from the brand logo. The results are committed.
