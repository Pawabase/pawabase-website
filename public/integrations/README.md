# Provider logo sources

Bundled locally so the interface does not depend on third-party image requests.
Google, GitHub, GitLab, LinkedIn, Slack, Facebook, Apple, and Okta marks are from [Devicon](https://github.com/devicons/devicon) (MIT). Discord, Twitch and Keycloak are from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). The Microsoft mark is from [Super Tiny Icons](https://github.com/edent/SuperTinyIcons) (CC0).

The OpenAI, Anthropic, Gemini, Mistral and Groq marks (AI gateway providers) are from [Lobe Icons](https://github.com/lobehub/lobe-icons) (MIT), version 1.101.0.

Brand names and marks are the property of their respective owners.

Agent tools and connections: Notion, DuckDuckGo, Model Context Protocol, Linear, Stripe and Supabase marks are from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0) version 16.36.0, filled with each brand's colour from Simple Icons' data. The Tavily and Hugging Face marks are from [Lobe Icons](https://github.com/lobehub/lobe-icons) (MIT) version 1.102.0, in colour.

More agent apps: Zapier, Neon, PostHog, Apify, Postman, monday.com, Airtable, Intercom, Shopify and Sentry are from [SVG Logos](https://github.com/gilbarbara/logos) (CC0) version 1.2.19, in full colour. Atlassian and X are from Simple Icons (CC0) 16.36.0, in Atlassian blue and black. Cloudflare, Exa, Firecrawl and xAI are from Lobe Icons (MIT) 1.102.0. DeepWiki and Context7 have no openly licensed mark in these sets, so Studio shows its own icons for them.
