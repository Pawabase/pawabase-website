# Pawabase brand-led homepage rebuild

## Creative premise

Pawabase is presented as the foundation ambitious software products grow from. The visual world pairs calm, precise technical design with the Cloud Kingdom as a selective atmospheric motif. Product interface captures provide evidence; the Little Automaton is a guide, not a repeated decoration.

## Design rules

- Do not repeat `heading → paragraph → cards` between adjacent sections.
- Use real Studio captures and existing media only; no fabricated dashboards, statistics, integrations, testimonials, or customer logos.
- Use the mascot in sections 1, 7, and 13 only.
- Keep copy product-led and concrete. Avoid “all-in-one,” “everything in one place,” and Studio-as-value-proposition language.
- Use dark ink, lavender, warm neutral text, precise borders, and the existing Jakarta family.
- Respect `prefers-reduced-motion`; no scroll-jacking or continuous expensive effects.

## Implementation order

1. Replace page shell, navigation, hero, and footer so the old visual structure cannot leak into the redesign.
2. Build the proposition, product experience, scenario gallery, and capability panorama.
3. Add developer experience, interlude, philosophy, ownership, ecosystem, and open-source sections.
4. Build the exploration and closing compositions.
5. Add responsive states and interactions, then capture 1440, 1280, 768, and 390 screenshots for review.
